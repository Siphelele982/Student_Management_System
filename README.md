* **Student Management System**

A Java Swing and JDBC project for managing students:

1.Add new students

2.View all students or filter by first letter

3.Update student details

4.Delete students with confirmation


**How to run**

1. Clone the repo

2. Import into NetBeans or any IDE

3. Configure `DBConnection.java` with your MySQL(eg.YOUR PASSWORD) settings

4. Run `Student\_Management\_System.java'
